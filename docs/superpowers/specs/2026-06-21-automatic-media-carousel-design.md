# WEIMETA 自动媒体轮播设计

## 目标

将当前“握拳＋捏合开启、张掌滑动切换”的媒体轮播改为自动播放模式。保留 6,000 前景粒子、握拳粒子魔方、魔方内部 Mini 素材、本地 Chrome 图片兼容和有声视频播放。

## 开启与结束手势

- 一只手稳定握拳，另一只手稳定张开五指约 0.3 秒后，自动开启前景媒体轮播。
- 开启轮播后，不再识别左右挥动来切换素材。
- 结束轮播需要两只手同时稳定握拳约 0.4 秒。
- 双拳结束后，当前前景素材缩小并收回粒子魔方，随后恢复普通握拳魔方状态。
- 单手短暂丢失、张掌手暂时不再张开，均不退出轮播，也不暂停当前视频。

## 自动播放规则

- 轮播按照媒体池顺序循环播放，不随机跳转。
- 图片完全居中后展示 3 秒，再进行下一项立方翻页。
- 视频取消循环；视频完全居中后开始有声播放，直到触发 `ended` 才切换下一项。
- 翻页过程中旧视频继续播放；新媒体完全居中后，旧视频才停止。
- 自动播放仅允许向下一项切换，不提供上一项操作。
- 切页动画进行中不重复触发下一项，避免索引错位。

## 五掌远近控制

- 轮播开启后，保持张开的五掌仅控制整个前景轮播画面的远近缩放。
- 手掌靠近摄像头时，轮播画面缩小并被推远。
- 手掌远离摄像头时，轮播画面放大并被拉近。
- 使用平滑插值和上下限限制，避免画面抖动或超出可视范围。
- 五掌的横向移动不再改变轮播位置，也不触发切页。

## 状态与容错

- 自动播放计时器只在当前媒体完全居中后启动。
- 图片计时、视频结束监听和切页动画互斥；退出轮播时全部清理。
- 当前视频因浏览器策略无法自动有声播放时，保持可见并允许用户点击播放，不提前跳过。
- 双拳退出优先级高于自动切页和远近控制。
- 退出完成后必须可以再次通过“拳头＋五掌”进入。

## 验证

- 自动测试覆盖：3 秒图片计时、视频结束切换、禁用手势切页、拳头＋五掌进入、双拳退出、五掌远近方向、退出后清理计时器。
- 手动模式提供自动轮播开启、远近模拟和双拳收回入口。
- 在单一浏览器标签页验证图片轮播、完整视频播放、自动切页、缩放、退出和第二次进入。
- 保持 Chrome `file://` 下 12 个素材与 Mini 预览正常显示。

# 手掌跟随 2D 立方轮播设计

## 目标

将所有粒子状态统一为 6,000 粒子，同时保留握拳粒子魔方和内部 Mini 素材。左手握拳、右手五掌时进入前景 2D 立方翻页轮播；轮播跟随右手掌移动，右手左右挥动切换素材，只有左手握拳持续丢失才退出。

## 交互

- 单手 1–5 与握拳形态继续保留，所有形态统一使用 6,000 粒子。
- 左手握拳时显示粒子魔方，12 个图片/视频 Mini 预览随机悬浮在魔方内部。
- 左手握拳稳定后，右手五指张开并稳定约 0.3 秒，直接进入前景轮播，不使用捏合。
- 右手五掌位置控制整个轮播画面的屏幕位置，移动使用平滑插值并限制在可视区域内。
- 右手五掌左挥显示下一项，右挥显示上一项；一次挥动只切一项。
- 右手丢失或不再张掌时，轮播停留在最后位置，当前视频继续播放。
- 只有左手握拳持续丢失超过容错时间才关闭轮播并返回普通手势。

## 视觉与播放

- 轮播为中央 2D 卡片的 CSS 3D 立方翻页：旧面与新面绕 Y 轴形成相邻立方体面。
- 图片和视频使用原始素材，`object-fit: contain`，不裁切、不贴到粒子魔方。
- 翻页开始后旧视频继续播放；新面完全转正后才停止旧视频，并启动新视频。
- 视频默认有声播放；若浏览器阻止自动有声播放，保留画面播放并显示“开启声音”按钮。
- 不显示参考视频中的标题、页码、箭头或说明文字。

## 验证

- 自动测试覆盖 6,000 粒子、张掌触发、左右挥动方向、右手丢失保持、左拳丢失退出和视频切换时机。
- 单一浏览器窗口验证图片清晰度、视频播放、跟手移动、连续两轮进入/退出和真实双手识别。

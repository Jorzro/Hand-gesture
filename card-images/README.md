# 图片与视频素材

素材目录：

`/Users/waneyzai/Documents/3D Rainbow cards/card-images/`

页面支持 12 个编号槽位：

- `card-01.jpg` 到 `card-12.jpg`
- 也支持 `.jpeg`、`.webp`
- 独立视频推荐使用 `video-01.mp4` 到 `video-12.mp4`
- 也支持使用 `card-01.mp4` 到 `card-12.mp4` 替代对应编号的图片

图片卡槽按照 `JPG → JPEG → WebP → MP4` 的顺序读取。使用 `video-XX.mp4` 时，视频会作为额外素材加入随机池，可以与同编号图片同时存在。

## JPG 图片建议

- 横图和竖图都可以，页面会保持原始比例。
- 推荐长边 1600–2400 像素。
- 单张建议不超过 2 MB。
- 五指星云中会出现这些照片的 mini 缩略图。
- 捏合选中后，图片会在画面中央放大展示。

## MP4 视频建议

- 使用浏览器兼容性较好的 H.264 编码和 AAC 音频。
- 推荐 1080p 或以下，单个文件建议不超过 20 MB。
- 捏合选中后会在画面中央循环播放。
- 为保证浏览器自动播放，默认静音播放。

增加或替换素材后刷新页面即可，不需要修改 HTML。
